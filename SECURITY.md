# Security

This is an early preview. Use copies of files and synthetic test data.
No independent security audit has been completed.

## Report a vulnerability

Use Security → Report a vulnerability on this repository when private
reporting is available. If it is unavailable, open an issue requesting a
private contact and keep technical details for the private conversation.

Include app version, operating system, possible impact and reproduction
steps using synthetic data. Do not publish private identities, archives,
contact codes, passwords or messages.

Maintainers aim to reproduce issues, assess affected versions and coordinate
disclosure. Fixes and known limits are described in release notes.
